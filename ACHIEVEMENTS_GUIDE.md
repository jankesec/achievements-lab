# GitHub Achievements & Badges Guide

This repository serves as a testing and reference lab for unlocking GitHub achievements:

- ⚡ **Quickdraw**: Close an issue or pull request within 5 minutes.
- 🚀 **YOLO**: Merge a pull request without code review.
- 👯 **Pair Extraordinaire**: Co-author a commit on a merged pull request.
- 🦈 **Pull Shark**: Merge multiple pull requests.
- 🧠 **Galaxy Brain**: Answer questions in GitHub Discussions.
- 🌟 **Starstruck**: Receive stars on your repositories.
- 💖 **Public Sponsor**: Sponsor open source creators.
